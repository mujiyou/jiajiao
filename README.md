# 家教老师筛选器

收到太多家教应聘简历筛不过来？把每位老师的**简历截图**传进来自动识别打分排序（粘贴文字也行）；再由你们打三个 10 分制的分：**试课、印象、耐心**。总分 = 试课 40% + 印象 30% + 简历综合 20% + 耐心 10%（权重可调，没打分的项自动按剩余权重折算）。

## 使用方法

无需安装任何东西：下载 `index.html`，用浏览器（电脑或手机）打开即可。所有数据（含图片）只保存在你自己的浏览器里（IndexedDB），不会上传到任何服务器。

### 国内 / 无外网环境使用

这个工具是**单文件网页**（约 8MB，识别引擎已内嵌），把 `index.html` 文件发过去就行，**包括截图识别在内的全部功能都离线可用**：

- **电脑（最推荐）**：微信/QQ 收到文件后下载，双击用浏览器打开（Edge、Chrome、360 等都可以）。如果双击打开的不是浏览器，就右键 →「打开方式」→ 选浏览器。
- **安卓手机**：微信里点开文件 → 右上角「···」→「用其他应用打开」→ 选浏览器（Edge、Chrome、夸克、QQ 浏览器等）。
- **iPhone**：iOS 对本地网页支持不好，建议用电脑，或让家里人代为录入。
- 数据保存在**打开它的那个浏览器**里：换电脑/换浏览器前，先点「导出备份」，在新设备上「导入备份」即可（备份含图片）。
- 每次收到新版本文件，直接用新文件打开即可，浏览器里的数据不会丢（数据不存在文件里）。

1. **设置筛选标准**：填写需要辅导的科目/年级（如「高中 数学」）、预算区间（元/小时），按需调整六个维度的权重。
2. **添加候选人**：
   - **方式一（推荐）**：上传简历/聊天截图，自动识别文字并打分。识别引擎和中文模型**已内嵌在文件里**（所以文件约 8MB），识别全程在本机完成、不需要联网，截图不会上传到任何服务器。**姓名和微信名会自动从识别文字里提取**（支持「姓名：X」「我叫X」「我姓周」「X老师」及微信聊天的「名字 + 日期」抬头格式）。
   - **方式二**：直接粘贴文字（识别错的字也在文字框里直接改）。识别不准时可用微信「长按截图 → 提取文字」替代。
   - 简历多的话可以用「批量导入」一次粘贴多份（用 `====` 行分隔）。
3. **你们的三项打分（都是 10 分制）**：点开候选人，给「试课」「印象（人怎么样）」「耐心」各打 1–10 分。**总分 = 试课 ×40% + 印象 ×30% + 简历综合 ×20% + 耐心 ×10%**；四个比例都可在「筛选标准 → 总分构成」里拖动调整；还没打分的项不计入，权重自动折算给其他项（比如都没打分时就按简历综合分排名）。明细里会显示完整算式。
5. **看排名**：候选人按总分从高到低排序，点开任意一位可以看到每个维度的得分和**具体加减分依据**（原文片段）。
6. **标记状态**：对每位候选人标记「通过 / 待定 / 淘汰」，写备注，最后导出表格（CSV，含微信名、试课分等全部列）或备份（JSON，含图片）。

## 打分维度

默认标准按当前需求预设：高一升高二数学物理巩固，**优先湖南参加高考、刚刚高中毕业的应届生**，有耐心、了解湖南高考，预算 130–150 元/小时。所有权重和关键词都可在「筛选标准」里随时调整。

**总分构成**（默认，可调）：试课 40%、印象 30%、简历综合 20%、耐心 10%。

**简历综合分**由下面五个维度加权得出：

| 维度 | 默认权重 | 依据 |
|------|---------|------|
| 湖南·应届 | 35 | 湖南参加高考（+35）或湖南本地背景（+25）；刚高中毕业/应届/准大一（+35），大一大二在读次之（+15） |
| 科目匹配 | 25 | 简历中是否提到所需科目/年级（默认：数学 物理 高中），识别「只辅导X」限定 |
| 学历成绩 | 20 | 院校层次（清北 / 985 / 211 / 一本）；应届生自动识别高考总分和数学/物理单科分，取更高者 |
| 教学经验 | 10 | 经验年数、带过的学生数、提分成果、教师资格证、自定义加分关键词（默认：三角函数 向量 立体几何 机械能 电学） |
| 价格匹配 | 10 | 自动识别报价（元/小时，分学段报价时优先取高中价），与预算区间（130–150）比对，低于预算不扣分 |

另有**红旗关键词**（默认：中介费、押金、定金、先付款、刷单）——命中即在卡片上醒目警示并扣总分，关键词可自行修改。

## 提示

- 印象和耐心的判断在微信里完成，试课分约完课再打，工具负责按权重折算总分并排序。
- 简历分是规则式的初筛参考，每一分都可核查依据；分数接近时以试课表现为准。
- 换浏览器或换设备前，记得先「导出备份」，再在新设备上「导入备份」（备份包含图片）。
