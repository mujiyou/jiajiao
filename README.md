# 家教老师筛选器

收到太多家教应聘简历筛不过来？把每位老师的**简历**和**微信聊天记录**粘贴进来，按你设定的标准自动打分排序，快速挑出值得约试课的人。

## 使用方法

无需安装任何东西：下载 `index.html`，用浏览器（电脑或手机）打开即可。所有数据（含图片）只保存在你自己的浏览器里（IndexedDB），不会上传到任何服务器。

### 国内 / 无外网环境使用

这个工具是**完全离线的单文件网页**，不依赖任何外网资源，打开后断网也能用。只要把 `index.html` 文件发过去就行：

- **电脑（最推荐）**：微信/QQ 收到文件后下载，双击用浏览器打开（Edge、Chrome、360 等都可以）。如果双击打开的不是浏览器，就右键 →「打开方式」→ 选浏览器。
- **安卓手机**：微信里点开文件 → 右上角「···」→「用其他应用打开」→ 选浏览器（Edge、Chrome、夸克、QQ 浏览器等）。
- **iPhone**：iOS 对本地网页支持不好，建议用电脑，或让家里人代为录入。
- 数据保存在**打开它的那个浏览器**里：换电脑/换浏览器前，先点「导出备份」，在新设备上「导入备份」即可（备份含图片）。
- 每次收到新版本文件，直接用新文件打开即可，浏览器里的数据不会丢（数据不存在文件里）。

1. **设置筛选标准**：填写需要辅导的科目/年级（如「高中 数学」）、预算区间（元/小时），按需调整六个维度的权重。
2. **添加候选人**：
   - **简历**两种方式：直接粘贴文字（能自动打分），或上传简历图片（供人工查看，关键信息建议补成文字）；
   - **微信聊天记录**：上传聊天截图（可多张，也支持把截图 Ctrl+V 粘进文字框），或粘贴聊天文字（能自动分析）；
   - 简历多的话可以用「批量导入」一次粘贴多份（用 `====` 行分隔）。
3. **人工打星**：点开候选人查看聊天截图（点图可放大），给「耐心」和「印象（人怎么样）」各打 1–5 星，星级计入「沟通表现」维度，且**优先于文字自动分析**。上传了截图还没打星的候选人会显示「📷 截图待打星」提醒。
4. **看排名**：候选人按总分从高到低排序，点开任意一位可以看到每个维度的得分和**具体加减分依据**（原文片段）。
5. **标记状态**：对每位候选人标记「通过 / 待定 / 淘汰」，写备注，最后导出表格（CSV，可用 Excel 打开）或备份（JSON，含图片）。

## 打分维度

默认标准按当前需求预设：高一升高二数学物理巩固，**优先湖南参加高考、刚刚高中毕业的应届生**，有耐心、了解湖南高考，预算 130–150 元/小时。所有权重和关键词都可在「筛选标准」里随时调整。

| 维度 | 默认权重 | 依据 |
|------|---------|------|
| 湖南·应届 | 30 | 湖南参加高考（+35）或湖南本地背景（+25）；刚高中毕业/应届/准大一（+35），大一大二在读次之（+15） |
| 科目匹配 | 20 | 简历和聊天中是否提到所需科目/年级（默认：数学 物理 高中） |
| 沟通表现 | 15 | 优先采用人工打星（耐心/印象，1–5 星换算为 20–100 分）；未打星时按聊天文字自动分析：礼貌用语、主动专业信号（试讲、了解孩子情况、备课、耐心、错题反馈）、表达完整度，扣减负面信号（涨价、临时改时间等） |
| 学历成绩 | 15 | 院校层次（清北 / 985 / 211 / 一本）；应届生自动识别高考总分和数学/物理单科分，取更高者 |
| 教学经验 | 10 | 经验年数、带过的学生数、提分成果、教师资格证、自定义加分关键词（默认：三角函数 向量 立体几何 机械能 电学） |
| 价格匹配 | 10 | 自动识别报价（元/小时），与预算区间（130–150）比对，低于预算不扣分 |

另有**红旗关键词**（默认：中介费、押金、定金、先付款、刷单）——命中即在卡片上醒目警示并扣总分，关键词可自行修改。

## 提示

- 聊天截图主要用来人工判断**耐心和人品**——工具帮你把截图和评分收在一处，判断还是由人来做。
- 粘贴聊天文字时建议只粘**老师发的消息**，自动沟通分会更准。
- 打分是规则式的初筛参考，每一分都可核查依据；分数接近时请以聊天截图里的耐心程度和试课表现为准。
- 换浏览器或换设备前，记得先「导出备份」，再在新设备上「导入备份」（备份包含图片）。
