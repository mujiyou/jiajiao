# 家教老师筛选器

收到太多家教应聘简历筛不过来？把每位老师的**简历**和**微信聊天记录**粘贴进来，按你设定的标准自动打分排序，快速挑出值得约试课的人。

## 使用方法

无需安装任何东西：下载 `index.html`，用浏览器（电脑或手机）打开即可。所有数据只保存在你自己的浏览器里（localStorage），不会上传到任何服务器。

1. **设置筛选标准**：填写需要辅导的科目/年级（如「高中 数学」）、预算区间（元/小时），按需调整五个维度的权重。
2. **添加候选人**：粘贴姓名、简历、微信聊天记录，点「添加并打分」。简历多的话可以用「批量导入」一次粘贴多份（用 `====` 行分隔）。
3. **看排名**：候选人按总分从高到低排序，点开任意一位可以看到每个维度的得分和**具体加减分依据**（原文片段）。
4. **标记状态**：对每位候选人标记「通过 / 待定 / 淘汰」，写备注，最后导出表格（CSV，可用 Excel 打开）或备份（JSON）。

## 打分维度

| 维度 | 默认权重 | 依据 |
|------|---------|------|
| 学历背景 | 30 | 院校层次（清北 / 985 / 211 / 双一流 / 一本），硕博加分，师范背景加分 |
| 教学经验 | 25 | 经验年数、带过的学生数、提分成果、教师资格证、在校/机构任教、自定义加分关键词 |
| 科目匹配 | 15 | 简历和聊天中是否提到你需要的科目/年级 |
| 沟通表现 | 20 | 聊天记录中的礼貌用语、主动专业信号（试讲、了解孩子情况、备课、反馈）、表达完整度，扣减负面信号（涨价、临时改时间等） |
| 价格匹配 | 10 | 自动识别报价（元/小时），与预算区间比对 |

另有**红旗关键词**（默认：中介费、押金、定金、先付款、刷单）——命中即在卡片上醒目警示并扣总分，关键词可自行修改。

## 提示

- 聊天记录建议只粘贴**老师发的消息**，沟通分会更准。
- 打分是规则式的初筛参考，每一分都可核查依据；分数接近时请以试课表现为准。
- 换浏览器或换设备前，记得先「导出备份」，再在新设备上「导入备份」。
